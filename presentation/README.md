# POWR — عرض ويب تفاعلي لمناقشة مذكرة التخرج

**عرض Web Presentation حقيقي (ليس PowerPoint):** كل شريحة شاشة UI مصممة يدويًا داخل
Stage ثابتة بنسبة 16:9 (1920×1080) تُقاس تلقائيًا مع أي حجم نافذة، مع كاميرا تتحرك
داخل المخططات، وخطوات كشف تصاعدي، وانتقالات Morph بين الشرائح المتتالية.

- المذكرة المرجع: `../مذكرة تصميم وإنجاز نظام معلومات لتسيير مكتبة العلو_260307_115909.pdf`
- فتح العرض: `index.html` مباشرة في المتصفح، أو عبر خادم محلي:
  `python3 -m http.server 8000` ثم افتح `http://localhost:8000`.

## التحكم

| المفتاح | الوظيفة |
|---|---|
| زر «بدء العرض بملء الشاشة» / `Enter` | إغلاق بوابة البدء + طلب ملء الشاشة تلقائيًا |
| `F` / نقر مزدوج / زر ⛶ | تبديل ملء الشاشة |
| `←` / `Space` / `Enter` | التالي (خطوة داخل الشريحة ثم الشريحة التالية) |
| `→` / `Backspace` | السابق |
| `Home` / `End` | أول / آخر شريحة |
| `O` أو `Esc` | فهرس الشرائح (نظرة شاملة مصغّرة) |
| `N` | ملاحظات المقدّم (ماذا تقول / نقطة التركيز / الانتقال) |
| `F` | ملء الشاشة |
| `H` | لوحة المساعدة |
| سحب باللمس | تنقّل (اتجاه RTL) |

## نظام التصميم

- **الألوان:** Deep Navy (`#071120 → #12263E`) + أزرق (`#3E7BFA`) + أبيض/رمادي فاتح
  (`#EDF3F9 / #B7C6D8`) + لون إبراز واحد نحاسي/ذهبي (`#E2B457`) مستلهم من طابع
  المكتبة والختم الأكاديمي. لا ألوان إضافية.
- **الخطوط (مستضافة محليًا في `fonts/`):** Alexandria للعناوين، IBM Plex Sans Arabic
  للمتـن، IBM Plex Mono للمعرِّفات التقنية (أسماء الجداول وSQL).
- **الحركة:** منحنى واحد `cubic-bezier(.22,1,.36,1)` للكشف، و`cubic-bezier(.32,.72,.24,1)`
  للكاميرا. لا Bounce ولا Spin: الحركة دائمًا حركة كاميرا/كشف تدريجي.
- **محرك الحركة GSAP 3.15** (مشروع [greensock/GSAP](https://github.com/greensock/GSAP) —
  رخصة GreenSock القياسية المجانية بالكامل منذ 3.13 بما فيها كل الإضافات)، مدمج محليًا
  في `js/vendor/` بدون CDN:
  - `gsap` core: كل كشوف الخطوات، الكاميرا السينمائية داخل المخططات، انتقالات الشرائح،
    الـMorph بين الشرائح (تحويل موقع/مقياس/استدارة زوايا)، نبض الأرقام، popover الأقسام،
    رفع البطاقات عند التحويم، وشريط التقدم.
  - `SplitText`: عناوين الشرائح والـlead تُكشف كلمةً كلمة/سطرًا سطرًا بقناع تدريجي.
  - `DrawSVGPlugin`: أسهم مخططات التدفق والشجرة تُرسم رسمًا تدريجيًا حقيقيًا.
  - `Flip`: مورف FLIP حقيقي بين الشرائح (التقاط حدود العنصر المصدر ومطابقته عبر
    `data-flip-id` في الشريحة التالية) لكيان الكتاب/المنخرط/يستعير/جدول الكتاب.
  - `ScrambleTextPlugin`: تأثير فكّ التشفير (decode) للمعرّفات اللاتينية عند كشفها:
    أرقام الأقسام، وسوم البطاقات، وشارات MCD/MLD/MPD.
  - `Observer`: تنقل بعجلة الفأرة (أسفل = التالي، أعلى = السابق) مع قفل زمني ومنع
    التعارض مع فهرس الشرائح.
  - [micku7zu/vanilla-tilt.js](https://github.com/micku7zu/vanilla-tilt.js) (MIT، ‏4k★):
    ميلان ثلاثي الأبعاد مع وهج خفيف على لقطات البرنامج وبطاقات التقنيات.
  - أزرار تنقل مغناطيسية تتبع المؤشر، واحترام `prefers-reduced-motion` بإطفاء الحركة
    المحيطية والميلان والـscramble.
  - عند غياب GSAP لأي سبب يعود العرض تلقائيًا لنظام الحركة CSS احتياطيًا.
- **الاستمرارية (Continuity):** عنصر `data-morph` ينتقل بقياسه وموقعه بين الشرائح
  المتتالية (كتاب: كيان MCD ← علاقة MLD ← جدول TBL_BOOK؛ وكذلك المنخرط/الطالب ويستعير).

## الأمانة العلمية

- كل أسماء الكيانات والعلاقات والجدول والحقول والتعدادات منقولة حرفيًا من المذكرة
  (MCD الشكل 04، قائمتا الكائنات والعلاقات، MLD، سكربتات SQL، المخطط النهائي الشكل 05).
- لقطتا البرنامج (`assets/app_main.png`, `assets/app_login.png`) مستخرجتان من صفحة 93
  في المذكرة دون تعديل المحتوى؛ وصورة الغلاف مقتطعة من خلفية الشاشة الرئيسية نفسها.
- لا أرقام أو نسب مُختلقة: ما هو منجز موصوف كمنجز، والأثر المستهدف موسوم صراحةً بأنه مستهدف.
