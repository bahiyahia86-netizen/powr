الدراسة التنظيمية — الفصل الثاني
R1

مدة الإعارة لا تتعدّى الأسبوع (07 أيام) ويمكن إرجاع الكتاب قبل انتهاء المدة.

R2

تُسلَّم للمنخرط استمارة إعارة فارغة عند كل إعارة، ويُسجَّل في ملف الإعارة كل ما استعاره المنخرط.

R3

تُعار الكتب لصاحب بطاقة الطالب فقط؛ وطيلة مدة الإعارة يكون الطالب مسؤولًا عن الكتب.

R4

المنخرط الذي ضيّع كتابًا أو أتلفه يُعاقب بإعادة ثمنه 05 مرات.

R5

من حق كل طالب جامعي الانخراط، وينخرط في السنة مرة واحدة ووحيدة؛ ويوجد جدول لتنظيم وقت الإعارة لكل السنوات.

R6

مذكرات التخرج في جهة خاصة، ويُمنح الباحثون ترخيص؛ وكل عرقلة للسير الحسن تؤدي إلى عقوبات حسب درجة خطورتها.

IMPACT ON MCD

أثر القواعد على التعدادات

يستعير — منخرط أو أكثر × كتاب أو أكثر: تعداد (0,N)/(0,N) مع تاريخي الإعارة والإرجاع.

ينخرط — مرة واحدة ووحيدة في السنة: (1,1)/(1,N) بين المنخرط والسنة.

يعاقب — عقوبة لمنخرط واحد ووحيد: (1,1)/(0,N) بين العقوبة والمنخرط.

يؤلف / تنشر / ينتمي — مؤلف واحد ووحيد، دار نشر واحدة، صنف واحد: (1,1)/(1,N).

مسار الأرشفة والاسترجاع (Delphi → SQL)

01

نسخ احتياطي: BACKUP DATABASE [My_Data] TO DISK = 'C:\Backup\My_Data.bak' WITH FORMAT, NAME = 'Full Backup'

02

تأكيد للمستخدم: «تم إنشاء النسخة الاحتياطية بنجاح».

03

قبل الاسترجاع: غلق الاتصال ثم ALTER DATABASE [My_Data] SET SINGLE_USER WITH ROLLBACK IMMEDIATE

04

استرجاع: RESTORE DATABASE [My_Data] FROM DISK = … WITH REPLACE ثم SET MULTI_USER وإعادة الاتصال.

05

تأكيد: «تم استرجاع النسخة الاحتياطية بنجاح» — والإجراء نفسه متاح من واجهة SQL Server بثلاث خطوات.

الخاتمة — الفصل الثالث

● المنجز فعليًا

قاعدة بيانات My_Data

تسعة جداول بمفاتيح أولية وأجنبية وعلاقات UPDATE CASCADE على SQL Server 2017 Express.

واجهة تطبيق Delphi 10.4

ست وحدات: ملف، إدارة المنخرطين، إدارة الكتب، الإعارة والاسترجاع، المستخدمون، الإعدادات.

منطق داخل القاعدة

إجراءات مخزنة لإضافة/تعديل/حذف المؤلف، وقادح (Trigger)، ومراقبة آلية للمدخلات.

أرشفة واسترجاع

نسخة احتياطية كاملة تُنشأ وتُسترجع من الواجهة ومن SQL Server.

الحد من الأخطاء الناتجة عن العمل اليدوي وتقليل الاعتماد على الوثائق الورقية.
